# خطوة سوا

التطبيق المنشور: https://forappll.github.io/khotwa-sawa/

حسابان مستقلان عبر Supabase Auth، مع قراءة مشتركة وإنجازات يكتبها كل حساب لنفسه فقط عبر RLS. لا تتضمن الملفات كلمات المرور أو مفاتيح الخادم السرية.

الخطوات الأساسية العشر تحرّك الشخصية، والاثنتا عشرة الإضافية تمنح ورودًا متحركة فوق الرأس. دودو تحتسب الصلوات الخمس دون محو العلامات اليدوية عند إلغائها. ظرف علامة مستقلة لليوم بدون تفاصيل.

صفحات يومنا والإحصائيات والمنافسة، تفاصيل اليوم للحسابين، المزاج، رسائل تشجيع جاهزة، مهام خاصة بنقاط، فائز اليوم وتقرير PDF. تظهر رسائل التشجيع أثناء فتح التطبيق، وليست إشعارات نظام عند إغلاقه.

الأسبوع من السبت إلى الجمعة بتوقيت الأردن. مهام الأيام مستقلة. يوم الجمعة يظهر تنبيه الحذف غدًا. تنظف وظائف pg_cron التقدم السابق السبت 00:00 مع إبقاء الحسابات وتعريفات المهام الخاصة. نزّل التقرير قبل الحذف؛ لا تتوفر إحصاءات عن الأسبوع المحذوف.

التثبيت من قائمة المتصفح؛ آيفون: مشاركة ثم إضافة للشاشة الرئيسية. ظهور زر التثبيت يعتمد على دعم المتصفح.

المصدر: mobile.html وmobile.css وmobile.js. يجمع index.html التنسيق والمنطق ويجب إعادة تجميعه بعد تعديل المصدر. app-config.js يحتوي رابط المشروع ومفتاح النشر العام فقط.

اجتازت حسابات الأسبوع، دودو، استقلال ظرف، النقاط وعد الورود اختبارات منطقية. تم اختبار الدخول للحسابين ونافذة التشجيع وتنزيل PDF فعليًا.

database.sql وupgrade-weekly.sql أرشيف للتهيئة السابقة. لا تعِد تشغيل upgrade-weekly.sql لأنه يتضمن تصفيرًا نهائيًا.
